The daily update desk.

Prepare a verified price file here. Publishing requires a repository maintainer to commit the downloaded file as data/prices.json in GitHub. This public page cannot change the live website.

1. Load current data or import JSON/CSV. 2. Edit prices and source dates. 3. Validate and download. 4. Upload the replacement file in GitHub and commit.

CSV columns: id,name,category,city,price,unit,date,kind,source. Categories: fuel, produce, meat, metals, currency, construction, electronics.

Verification checklist

Use the source's effective date, correct unit, city and variant. Include an HTTPS source link. Keep the last known date if the source has not changed. Never use 0 as an unavailable price; omit the quote instead.
